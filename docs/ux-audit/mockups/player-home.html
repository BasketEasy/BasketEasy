Ce qui change

  • Les tuiles de stats disparaissent pour un joueur. DashboardPage.tsx:180-192 lui sert deux compteurs (« Événements — 7 prochains jours », « En attente de réponse ») : un chiffre, pas une action. La section « À répondre » est ce compteur, rendu actionnable.
  • Le RSVP se fait depuis l’accueil. Aujourd’hui AgendaRow (DashboardPage.tsx:46-73) renvoie vers …/teams/:teamId?tab=events — la page équipe, pas l’événement : 3 taps + une recherche visuelle avant de pouvoir répondre. Ici : 1 tap.
  • Fenêtre 7 j → 14 j. Le match du samedi 12 est invisible aujourd’hui (dashboard.service.ts:7, DEFAULT_AGENDA_WINDOW_DAYS = 7). GET /me/dashboard accepte déjà from/to — aucun changement serveur.
  • « Après le match » est une surface neuve : la fenêtre de vote dure 5 jours (voteWindow.ts:9) mais un match passé ne peut jamais apparaître dans une fenêtre now → +7 j. Le vote MVP est aujourd’hui pratiquement introuvable.
  • La grille « Mes équipes » (DashboardPage.tsx:221-242) est supprimée : elle duplique MyTeamsPage.tsx:156-160, désormais un onglet permanent de la barre basse.

Nouveaux besoins API

  • MyAgendaEvent (my-dashboard.ts:4-20) n’a ni venue, ni timeConfirmed, ni logistics : les badges « Domicile », « Heure à confirmer » et « Vous apportez les chasubles » sont impossibles aujourd’hui.
  • Compteurs de présence par événement (rsvpSummary) — sinon un GET …/rsvps par ligne.
  • Score du match : n’existe que dans ParsedScoresheetData (scoresheet-extraction.ts:48-61), derrière la confirmation d’un manager.
