Kluvo — planches « player-first »

Sept planches haute fidélité et trois wireframes de flux pour la refonte centrée joueur. Les variantes joueur et manager sont montrées côte à côte partout où l’écran diffère.

docs/ux-audit/mockups/ · généré le 2 septembre 2026

Comment lire ces planches

Chaque planche est un fichier HTML autonome, rendu avec les jetons réels de packages/@basketeasy/ui/tailwind-preset.cjs et les deux polices Parquet (Big Shoulders Display, Atkinson Hyperlegible). Les téléphones sont à 390 px, les vues desktop à 980 px. Les encadrés bleu-vert expliquent ce qui change par rapport au code actuel (avec les références fichier:ligne) ; les encadrés orange listent ce que l’API ne sait pas encore servir. L’analyse complète : docs/ux-audit/player-journey.md.
