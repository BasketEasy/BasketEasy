Règle 5

Secondaire = repliable

Ce qu’on ouvre rarement devient un SectionAccordion : titre + résumé d’une ligne tiré des données déjà chargées, sinon pas de résumé. Le bloc principal reste ouvert. Desktop : la paire principale côte à côte.

Règle 3

Info manquante = tuile accent

Quand un fait manque et que le lecteur peut le compléter : Card inset tone accent, IconBadge accent, une phrase, un bouton plein. Pour les autres lecteurs : le fait neutre, sans bouton.

Règle 6

Icône sur mobile, libellé sur desktop

Une action secondaire dans un en-tête est un bouton icône 36 px sous md (aria-label), libellé à partir de md. L’action principale garde toujours son libellé.

Règle 8

Listes : trois formes

Événement = carte + TimeBlock (plein pour un match, bordé pour un entraînement). Personne = ligne Avatar + nom + badge. Lien = ligne titre/méta + chevron, dans une Card flush.
